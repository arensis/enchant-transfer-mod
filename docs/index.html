Enchant Transfer

Extract, transfer, and combine enchantments through Magic Cards — now with colored cards, attachable modules, and an XP conversion system.

Requires: Fabric Loader and Fabric API · Minecraft 26.2 | 1.21.11

Languages: English · Español · Português (Brasil)* · Русский* · 简体中文* (*pending review)

CurseForge · Modrinth · GitHub · Issues

Enchant Transfer adds a craftable block — the Transfer Table — that lets you extract enchantments from any item into individual Magic Cards, apply those cards to other compatible items, and combine two cards of the same enchantment and level to upgrade them. All operations are free (no XP cost), and vanilla enchantment compatibility rules are respected.

Version 2.0 introduced the Module System: specialized blocks that attach to the Transfer Table on any face, extending its capabilities.

Version support

New features and modules are developed for Minecraft 26.x only. The 1.21.11 version (v2.0.x) is in maintenance mode and will only receive critical bug fixes.

Transfer Table

Requires an iron pickaxe or better to mine (the same applies to the Infusion Coil and the Zinc Smelter).

The 3D model reflects its recipe — gold on the outer edge, redstone in the middle ring, carbon-black inner layer, and a blue diamond core that glows from every angle.

Core Features

Extract

Remove enchantments from any enchanted item or book. Each enchantment becomes its own Magic Card, color-coded by category.

Apply

Place a Magic Card and a target item in the Transfer Table. The enchantment transfers instantly, respecting vanilla incompatibility rules.

Combine

Two cards of the same enchantment and level produce one card of the next level, up to vanilla maximum. Stacks work too — 5 + 6 cards yields 5 upgraded and 1 remainder.

Zero cost

All Transfer Table operations — extraction, application, and combination — are completely free. No XP, no materials consumed.

Module System

The Transfer Table now works as a hub. Specialized module blocks can be placed on any of its 6 faces. Right-click the Transfer Table to open the Selector Screen — a visual hub showing all connected modules with their real-time status.

  • Up to 6 modules per Transfer Table (one per face)
  • Each module type adds different functionality
  • Navigate between the hub and any module using the dot navigation bar
  • Modules show live status in the Selector — processing progress, tank levels, and connection state

Card Deck

The card is consumed and sets the deck's type. The Rarity wildcard uses a Curse (black) card.

How to use

  • Right-click a card onto the deck (or the deck onto a card) to store it, like a bundle
  • Right-click with a deck in hand to open it: its cards in a grid, with a points bar and a reserve bar, to move cards in and out at a glance (Shift + click works). The 64-point limit still applies
  • Right-click with an empty cursor to take the last stack back out
  • Each deck only takes cards of its own type; the Rarity wildcard takes Curse cards
  • A level N card is worth 2N−1 points (the same ratio as combining). Each deck holds up to 64 points

Deck Lectern

The block that holds your decks: a low brass base with a tilted velvet tray for 3 decks, under a glass bell. Place lecterns where regular bookshelves would go around an Enchanting Table; one ring of 16 at table height already reaches the cap of 15.

Deck Lectern
  • Placement: only counts at the same height as the enchanting table. Its glass bell fills the whole column, so nothing can be placed on top of it (and it can't go under a block) — that's why it's worth two bookshelves
  • Right-click opens a small screen with 3 deck slots; hovering the amethyst gem shows what the lectern gives a table on its own, next to each maximum (category and enchantment factors, power, wear reserve)
  • Lamps, one per slot: dark brown (no deck), light (deck without cards), emerald (deck with cards)
  • Off by default. Shift + right-click switches it on (it needs a deck with cards) or off: while it's on, the amethyst on top glows and runes fly to the enchanting table. It switches itself off when its decks run out of cards, never on

Influence markOptions changed by the decks show a small card in their top-right corner and an Influenced by card decks line in their tooltip

No marks? That's normal

Decks tilt the odds, they don't pick for the table: when it would have rolled the same enchantment anyway, the option isn't marked and costs no card. Some rolls show no marks at all — you'll see more with fuller, more specialized decks and higher table levels. The rolls only change after you enchant something, so re-placing the item shows the same options.

For modpacks

Affinities are datapack JSON files in data/<namespace>/enchanttransfer/library_affinity/ and reload with /reload. Add rules for any dimension or biome, including other mods':

{
  "deck": "enchanttransfer:card_deck_purple",
  "dimension": "twilightforest:twilight_forest",
  "enchantments": ["minecraft:loyalty"],
  "multiplier": 2.0
}

deck and multiplier are required; dimension, biome (id, list or #tag) and enchantments are optional.

Infusion Coil

How it works

  • Insert a Magic Card into the card slot — the coil processes it over ~10 seconds
  • XP is stored in an internal tank (1,000 XP capacity)
  • Place glass bottles in the bottle slot to extract XP as Bottles o' Enchanting (7 XP per bottle)
  • Unenchanted cards yield a minimum of 5 XP; enchanted cards yield more based on their enchantment

Tip

The Infusion Coil stays vertical regardless of which face it's attached to. The copper connector stub always points toward the Transfer Table.

  1. Make sure Minecraft runs with the Java version listed for your Minecraft version
  2. Install Fabric Loader for your Minecraft version
  3. Download Fabric API for the same Minecraft version and place it in the mods/ folder

Fabric API is required

The mod will not start without it. Make sure the mod file, Fabric API, and Fabric Loader all match your Minecraft version.

Compatibility with 3.0.x worlds

Worlds created with Enchant Transfer 3.0.x are fully compatible: nothing in them changes, and an Enchanting Table without Deck Lecterns nearby works exactly like vanilla.

Cards extracted before 3.1 keep their color (e.g. yellow Mending, green Soul Speed, or blank Knockback cards) but still go into the deck of their current category — decks check the enchantment, not the card color.

Compatibility with 1.0.x worlds

Worlds created with Enchant Transfer 1.0.x are fully compatible. Existing Transfer Tables keep working — the block ID hasn't changed.

Old Magic Cards stored in chests retain their enchantment data. They will appear as the generic (blank) card variant; their functionality is unchanged. New cards extracted after updating will automatically use the color-coded system.

Enchant Transfer adds a craftable block — the Transfer Table — that lets you extract enchantments from any item into individual Magic Cards, apply those cards to other compatible items, and combine two cards of the same enchantment and level to upgrade them. All operations are free (no XP cost), and vanilla enchantment compatibility rules are respected.

Version 2.0 introduced the Module System: specialized blocks that attach to the Transfer Table on any face, extending its capabilities. The first module — the Infusion Coil — converts Magic Cards into stored XP and fills glass bottles into Bottles o' Enchanting.

Version support: New features and modules are developed for Minecraft 26.x only.
The 1.21.11 version (v2.0.x) is in maintenance mode and will only receive critical bug fixes.

Core Features

  • Extract enchantments from any enchanted item or book into individual Magic Cards, each one color-coded by category
  • Apply cards to other compatible items, respecting vanilla incompatibility rules
  • Combine two cards of the same enchantment and level to get the next level (up to vanilla max). Stacks work too — 5 + 6 cards yields 5 upgraded and 1 remainder
  • Zero cost — all Transfer Table operations are completely free. No XP, no materials consumed

Card Decks (New in 3.1)

Brass-bound decks that store Magic Cards of one type. Place them in a Deck Lectern near an Enchanting Table and the table gains power and starts favoring what you've stored.

How to use

  • Right-click a card onto the deck (or the deck onto a card) to store it, like a bundle; right-click with an empty cursor to take the last stack out
  • Each deck only takes cards of its own type; the Rarity wildcard takes Curse cards
  • A level N card is worth 2N-1 points; each deck holds up to 64 points

At the Enchanting Table

  • Power — Every 3 decks holding cards count as one bookshelf (a full Deck Lectern = 1), adding up with regular bookshelves (cap of 15)
  • Category decks — Favor their category, and even more the exact enchantments stored (up to ×3)
  • Rarity wildcard — Favors rare, low-weight enchantments
  • Location affinity — Combat ×2 in the Nether (Fire Aspect ×3), fire protections and Flame ×1.5 in the Nether, Arcane ×2 in the End, Nature depends on the biome
  • Wear — Each enchantment the library helps with has a 20% chance to consume a card
  • Modpack friendly — Affinities are datapack JSON (data/<namespace>/enchanttransfer/library_affinity/) for any dimension or biome

Deck Lectern

  • Holds 3 decks on a tilted tray under a glass bell; right-click opens its 3 slots
  • One lamp per slot: dark brown (no deck), light (deck without cards), emerald (deck with cards)
  • Shift + right-click toggles it: the amethyst on top glows while active; inactive lecterns are ignored

Module System (New in 2.0)

The Transfer Table now works as a hub. Specialized module blocks can be placed on any of its 6 faces. Right-click the Transfer Table to open the Selector Screen — a visual hub showing all connected modules with their real-time status.

  • Up to 6 modules per Transfer Table (one per face)
  • Each module type adds different functionality
  • Navigate between the hub and any module using the dot navigation bar
  • Modules show live status in the Selector — processing progress, tank levels, and connection state

Infusion Coil (New in 2.0)

The first module for the Transfer Table. A vertical flask made of copper, brass, and glass that converts Magic Cards into XP.

How it works

  • Insert a Magic Card into the card slot — the coil processes it over ~10 seconds
  • XP is stored in an internal tank (1,000 XP capacity)
  • Place glass bottles in the bottle slot to extract XP as Bottles o' Enchanting (7 XP per bottle)
  • Unenchanted cards yield a minimum of 5 XP; enchanted cards yield more based on their enchantment

Tip: The Infusion Coil stays vertical regardless of which face it's attached to. The copper connector stub always points toward the Transfer Table.

Compatibility

Worlds from 1.0.x are fully compatible. Existing Transfer Tables keep working — the block ID hasn't changed. Old Magic Cards stored in chests retain their enchantment data. They will appear as the generic (blank) card variant; their functionality is unchanged. New cards extracted after updating will automatically use the color-coded system.
